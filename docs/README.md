# Documentation

This directory contains all project documentation.

The documentation evolves together with the source code and follows the same versioning strategy.

## Documents

| File | Description |
|------|-------------|
| architecture.md | High-level architecture and infrastructure design |
| roadmap.md | Project roadmap and milestones |
| conventions.md | Development standards and conventions |
| decisions.md | Summary of architectural decisions |
| journal.md | Technical journal and project history |
| adr/ | Architecture Decision Records |

## Principles

Documentation is treated as code.

Every significant architectural or implementation decision should be documented before being implemented.

This ensures that the project remains reproducible and understandable over time.
