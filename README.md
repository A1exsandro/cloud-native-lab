# Cloud Native Lab

🚧 Work in Progress

A complete Cloud Native Platform built on Oracle Cloud Always Free.

## Goals

- Infrastructure as Code with Terraform
- Configuration Management with Ansible
- Kubernetes with RKE2
- GitOps with ArgoCD
- Observability
- Security
- CI/CD
- Cloud Native Applications

This repository documents the entire journey from an empty Oracle Cloud account to a production-like Kubernetes platform.
